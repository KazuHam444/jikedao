# 背景图片配置说明

## 📸 如何更换背景图片

### 方法一：使用在线图片（当前方式）

当前使用的是 Unsplash 的免费图片。如果你想更换，只需要修改各个页面中的 `background-image` URL。

**修改位置：**
- `frontend/src/views/Login.vue` - 登录页面
- `frontend/src/views/Register.vue` - 注册页面
- `frontend/src/views/Home.vue` - 首页
- `frontend/src/views/AdminLogin.vue` - 管理员登录页面

**示例：**
```css
background-image: url('https://images.unsplash.com/photo-你的图片ID?w=1920&q=80');
```

**推荐的免费图片网站：**
- Unsplash: https://unsplash.com
- Pexels: https://www.pexels.com
- Pixabay: https://pixabay.com

### 方法二：使用本地图片（推荐）

1. **创建图片目录**
   ```
   frontend/public/images/
   ```

2. **放置图片文件**
   将你的背景图片放在 `frontend/public/images/` 目录下，例如：
   - `login-bg.jpg`
   - `register-bg.jpg`
   - `home-bg.jpg`
   - `admin-bg.jpg`

3. **修改CSS引用**
   在各个页面的 `<style>` 中修改：
   ```css
   background-image: url('/images/login-bg.jpg');
   ```

### 方法三：使用CSS渐变（无需图片）

如果不想使用图片，可以使用纯CSS渐变背景：

```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

或者更复杂的渐变：
```css
background: linear-gradient(135deg, 
  #667eea 0%, 
  #764ba2 50%, 
  #f093fb 100%);
```

## 📝 修改步骤示例

### 示例：更换登录页面背景

1. 找到 `frontend/src/views/Login.vue` 文件
2. 找到 `.login-container` 样式
3. 修改 `background-image` 属性：

```css
.login-container {
  /* 使用本地图片 */
  background-image: url('/images/my-login-bg.jpg');
  
  /* 或者使用在线图片 */
  background-image: url('https://your-image-url.com/image.jpg');
  
  /* 或者只使用渐变 */
  /* background-image: none; */
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
```

## 💡 提示

1. **图片大小**：建议使用 1920x1080 或更大的图片，确保在不同屏幕上显示清晰
2. **文件格式**：推荐使用 JPG（文件小）或 WebP（现代浏览器，质量好）
3. **性能优化**：如果使用大图片，考虑压缩优化
4. **响应式**：背景图片会自动适配不同屏幕尺寸
