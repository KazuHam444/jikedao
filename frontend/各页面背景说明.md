## 🔄 如何更换背景图片

### 方法一：使用本地图片（推荐）

1. **创建图片目录**
   ```
   frontend/public/images/
   ```

2. **放置图片文件**
   - `login-bg.jpg` - 登录页
   - `register-bg.jpg` - 注册页
   - `home-bg.jpg` - 首页
   - `write-bg.jpg` - 写信页
   - `letters-bg.jpg` - 我的信件页
   - `letter-detail-bg.jpg` - 信件详情页
   - `admin-login-bg.jpg` - 管理员登录页
   - `admin-bg.jpg` - 管理员后台

3. **修改CSS引用**
   在各个页面的 `<style>` 中修改：
   ```css
   background-image: url('/images/login-bg.jpg');
   ```

### 方法二：使用在线图片

直接修改 `background-image` 的 URL：

```css
background-image: url('https://你的图片链接.com/image.jpg');
```

### 方法三：使用纯CSS渐变

删除 `background-image` 行，只使用渐变：

```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

## 📝 修改示例

### 示例：更换登录页面背景

1. 找到 `frontend/src/views/Login.vue` 文件
2. 找到 `.login-container` 样式
3. 修改 `background-image` 属性：

```css
.login-container {
  /* 使用本地图片 */
  background-image: url('/images/my-login-bg.jpg');
  
  /* 或者使用在线图片 */
  background-image: url('https://your-image-url.com/image.jpg');
  
  /* 或者只使用渐变 */
  /* background-image: none; */
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
```

## 💡 提示

1. **图片大小**：建议使用 1920x1080 或更大的图片
2. **文件格式**：推荐 JPG（文件小）或 WebP（质量好）
3. **性能优化**：大图片建议压缩优化
4. **响应式**：背景图片会自动适配不同屏幕
5. **遮罩层**：每个背景都有渐变遮罩层，可以调整透明度来改变视觉效果

---

## 🔧 调整遮罩层透明度

如果想改变背景图片的显示效果，可以调整 `::before` 伪元素的透明度：

```css
/* 更透明（背景图片更明显） */
background: linear-gradient(135deg, rgba(102, 126, 234, 0.5) 0%, rgba(118, 75, 162, 0.5) 100%);

/* 更不透明（背景图片更模糊） */
background: linear-gradient(135deg, rgba(102, 126, 234, 0.9) 0%, rgba(118, 75, 162, 0.9) 100%);
```
